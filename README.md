# Diplodoc Playground (deprecated)

This standalone repository is deprecated. Development continues in the
[Transform playground](https://github.com/diplodoc-platform/transform/tree/master/playground).

- [Open the maintained playground](https://diplodoc-platform.github.io/transform/?prefill=true).
- [Report issues or contribute](https://github.com/diplodoc-platform/transform).

The maintained playground is built with the current Transform sources and published
when a Transform release is published. Please use it for testing YFM syntax.

This repository is kept for historical reference and is not archived.
